# Tiny Transformer

Reserved for the team's tiny Transformer component. No experiment or checkpoint is claimed here yet.

When the work is ready, add the implementation, configuration, saved model weights or checkpoint, results, and reproduction instructions in this directory. For the [project-wide demo](../project_demo.ipynb) to display the results automatically, add `results/summary.csv` (any labeled tabular columns are accepted) and, optionally, `results/figure.png`. The notebook reads the latest repository `main` when opened in Colab, so newly committed results appear on its next run.
